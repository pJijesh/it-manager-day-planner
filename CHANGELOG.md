# Changelog

All notable changes to this project are recorded here. The format follows

### Added

- First public release: day and week planner for IT managers: an operating rhythm, printable templates, and a tested tool that builds a time-blocked plan with protected time for interruptions.
- See the README for scope, what has and has not been verified, and the roadmap.
